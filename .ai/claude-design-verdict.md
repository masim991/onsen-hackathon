# Claude Code 디자인 재검토 · 2026-11-25

기존 `가을 료칸 입구 동선 검토` Claude Code 세션에 사용자가 제시한 FUDO, Ameen Abdullah, Doors, Shaders 링크와 CodePen·Three.js Forum·Sketchfab 조사 키워드, 현재 로컬 사이트 및 데스크톱·모바일 캡처를 전달했다. Claude는 코드를 수정하지 않고 로컬 입장→지도→간토→군마 배너를 직접 클릭했다.

## 판정

**수정 후 가능.** 흐름은 끝까지 작동하지만 현재는 하나의 료칸을 걷는 경험보다 사진 여러 장을 이어 붙인 인터랙티브 데모로 보인다는 평가다.

## 주요 결함

1. **P0 입장 카메라 불연속:** 문 너머 작은 방, 넓은 실내, 지도 페이지의 좌탁 접사가 서로 다른 장소와 색온도로 보인다. `effects-door.png`의 문짝 직사각 클립 경계도 눈에 띈다.
2. **P0 지도 보드의 물성:** `effects-map-final.png`에서 보드가 좌탁 가장자리를 넘어 의자 쪽까지 퍼지고 화면 하단에서 잘려, 종이보다 경사진 간판처럼 보인다. 일본 지형은 보드 가로의 약 35%만 차지한다.
3. **P1 모바일 구성:** 거의 전폭의 보드가 좌탁을 가려 방의 맥락이 약하다. 라벨은 12px·약 33px 터치 높이로 작고 일부 육지와 규슈 남서쪽 섬이 가려진다.
4. **P1 지도 재질·타이포:** 짙은 청록 지형과 여러 겹의 그림자가 플라스틱 UI처럼 보이고, 시코쿠 라벨이 바다 위에 뜬다. 홋카이도 인셋은 스티커처럼 보인다. FUDO의 강한 타이포 위계에 비해 현재 제목은 약하다.
5. **P1 효과의 설득력:** Claude가 제안했던 증기·문틈 투과광·물결은 코드에 있지만 제공된 정지 캡처에서 충분히 보이지 않았다. 실제 움직임은 판단하지 않았으며, 프레임별로 증명되지 않으면 제거를 권했다.

배너는 흐름 중 가장 잘 정리된 화면이라는 평가다. 숫자가 로컬 값에서 원격 값으로 바뀔 가능성과 선택 직후 호버 잔상은 P2로 지적했다.

## 제안된 수정 순서

1. 좌탁과 종이의 공간 관계를 다시 잡고 일본 지형이 종이를 더 채우게 한다.
2. 문 너머부터 지도까지 한 방·한 카메라 시점으로 통일하고 문짝 클립 경계를 정리한다.
3. 지형 색·그림자를 종이/먹 계열로 낮추고 시코쿠 라벨과 홋카이도 인셋을 정리한다.
4. 모바일에서 좌탁 상판을 보이게 하고 터치 라벨을 44px 이상으로 키운다.
5. 증기·빛·물결을 시간별 프레임으로 확인한 뒤 유지 여부를 결정한다.

## 레퍼런스·검증 범위

- FUDO는 직접 열어 대형 타이포, 사진 그리드, 스크롤 텍스트 리빌을 확인했다.
- Ameen Abdullah는 파티클 로딩 화면까지만, Doors는 로딩 후 파란 포트폴리오 화면까지만 봤다. 문 열림 연출 자체는 확인하지 못했다.
- Shaders는 이번 재검토에서 다시 열지 않았다. Spline·Framer, CodePen·Three.js Forum·Sketchfab은 평가하지 않았다.
- 모바일 375×812에서 가로 넘침은 없고 라벨 최소 높이는 약 33px이었다. WebKit·실기기 FPS·reduced-motion 실행과 정밀한 모션 품질은 검증하지 않았다.
