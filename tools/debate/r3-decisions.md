# Round 3 결정 (이미지·기능·활용성·불편 + 사진 없는 시설)

근거: r3-image / r3-function / r3-usability / r3-pain / r3-photoless-design / r3-photoless-sourcing.md
핵심 수치: 목록 1,015곳 중 사진 85(8%), 사진 없음 930(92%, 모두 료칸). 사진 없는 곳의 97%는 요금·온천수 모두 없음. 공식 사이트 URL은 사진 없는 곳의 53%.
총평: "찾기"는 되지만 "비교"가 없고 "예약 이동"이 약하며, 930장의 카드가 똑같아 보여 고장난 것처럼 느껴진다.

## 채택 (이번에 구현)
1. 카드에 공식 사이트 버튼(hp 있을 때), 서랍 맨 위에 공식 사이트 주 버튼 1개. 출처 링크가 같은 주소면 중복 표시 안 함.
2. 사진 없는 카드: 첫 글자 칩 → 도도부현 2글자 칩. 한 줄에는 "아는 값만"(공식 사이트·당일입욕·확인일) 표시. "미확인" 문구는 목록 위 안내 1회 + 서랍에서 유지.
3. 서랍(사진 없음): 큰 회색 박스 → 56px 띠 "사진 미등록". 지역 문구 중복 제거. 모든 값이 없으면 한 줄로 접기(기존 결정 P4 구현 확인).
4. 카드·서랍 사진: Commons 원본 → 같은 호스트의 폭 지정 썸네일(640/960), width/height·aspect-ratio 지정. 카드 크레딧은 짧게, 전체는 서랍.
5. 비교 트레이: 찜한 시설 2~4곳을 표로 나란히(가격·온천수·당일입욕·지역·공식 사이트·확인일). 값 없음은 "확인되지 않음". 건강/추천 문구 금지.
6. 필터: 건수 0인 항목 숨김, #richOnly를 "사진 있는 곳 N" / "가격 있는 곳 N"으로 분리, 예산 슬라이더 옆에 "가격 확인 N곳 / 미공개 M곳 포함" 줄, 0건이면 "마지막 조건 해제" 버튼, 온천지 드롭다운 중복(구로카와/구로카와온천/구로카와 온천) 정규화, 페이저 쪽 번호 점프.
7. 모바일: 700px 이하 스택 고정 해제(잘림 방지), 44px 터치 타깃, 중복 "온천 찾기" 메뉴 제거, 메뉴 잘림 수정, 모바일에서 필터 요약 + "N곳 보기" 고정 버튼.
8. 문구: 커버 "湯けむりの宿へ" 번역, 영어 로마자 오류(Okuoyaseukyo, Niseko gosiki), 일본어 브랜드명 통일, URL의 ?nointro= 정리.
