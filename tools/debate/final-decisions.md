# Debate result (10 voices, 2 rounds) → final upgrade decisions

Voices: architecture, information-UX, security, price/FX, data-freshness, location, content, accessibility+performance, visual-design critic, end-user personas.

## Unanimous / near-unanimous DO NOW
- P3 bugs: hide the pager when total <= page size and always show the filtered total; recompute facility-kind filter counts from the current result set (they currently exceed the 1,015 total); announce result count via aria-live.
- P2 price honesty: when the price slider is active show "가격 확인 N곳 / 전체 M곳" (ja 価格確認済み N件 / 全M件, en "N of M have a price") with a toggle to include unpriced facilities (DEFAULT = included so nobody gets an empty page; null price never shown as 0 or hidden silently). Cards without price show "가격 미공개 · 공식 사이트에서 확인" (localized) and the drawer puts booking/official links at the top when no price exists.
- P8 mobile: every interactive element >= 44px tall at <=640px (padding only); the favorites heart reachable in the fixed top bar on phones with a count toast (textContent only, aria-live).
- P16 keep state across language switch: carry `?q=`, region/pref/kind filters and `#<facility id>` in the URL (allow-list parsing: lang enum, numeric/known ids only; never write raw location into HTML).
- P13 security: esc() in web/sources.js template (description, terms, author, credit, caption, urls via safeUrl); tools/security/check.mjs must also scan page.js, cover.js, footer.js, intro.js, hires.js; tools/export-catalog.mjs must run the esc/safeUrl pass and fail on `<`, `javascript:` or non-https URLs.
- P10 FX: ignore data/fx.json when fetchedAt is older than 36 h (fall back to live sources); cache stores status/stale; show an "(old rate)" tag in ko/en when stale; refresh interval 30 min; one-line "indicative rate" note under the budget slider; yen original stays beside converted amounts.
- P14 content (first-timer): real page sections (no JS-only popup) — etiquette block on guide/water pages in ko/ja/en using ONLY these safe, common manners phrased with "usually / follow the facility's posted rules": wash and rinse before entering; keep towels out of the bath water; tie long hair up; swimsuits are normally not worn; bathe quietly, no swimming or diving; dry off a little before the changing room; most baths are separated by gender (mixed baths exist). Tattoos: only "policies vary — ask the facility in advance". NO claims about water temperature, bathing duration, health, efficacy, how common mixed bathing is, or that all facilities follow the rules. Water-type chips/tags in the list and drawer link to `water*.html#<type>` anchors (ids on the guide cards; map the 10 site water types to the cards, merging where the page merges); price/stay tiles and the drawer "check before visiting" link to `guide*.html#...`; each guide ends with a CTA back to `index.html#results`.

## MODIFY (agreed form)
- P1 photo-less cards: keep name order (user-decided; no data-first default sort). A card without a photo is a compact ~84px row in the same 4-column grid: 56px teal chip with the onsen icon + initial, name, area, one muted line "요금·온천수 미확인 · 확인일". Optional link above the list "사진·가격 있는 곳만" (filter, not a sort).
- P4 drawer: when all four fact tiles are "not confirmed" collapse them into ONE line ("요금·온천수·입욕 정보 미확인 · 확인일") with the source/official CTA above it; keep individual "미확인" wording when only some tiles are empty. Never hide that something is unconfirmed.
- P5 cover/hero: cover height ~64svh (search bar above the fold at 1440x900 and 375x812); intro shown once per 14 days (localStorage TTL, fall back to sessionStorage), no double hero; user-decided cover-to-fixed-header stays.
- P6 performance WITHOUT lowering hero quality: keep >=1280w hero (1920 on wide screens), `fetchpriority="high"` + `decoding="async"` on the first hero image, `<link rel=preload as=image>` for it, later slides after idle; merge the 3 Google Fonts CSS requests into one (display=swap, preconnect both hosts, only used weights); `defer` non-critical scripts (cover/motion/footer/survey); `content-visibility:auto` + contain-intrinsic-size on cards; add `width`/`height` to card/drawer images.
- P7 fonts: Gaegu only for hero h1, section h2 and region-tile names (>=24px); Gowun Dodum for body, buttons, card titles, drawer, ko/en body; Klee One only for ja headings/hero; remove the dead Nanum Brush Script rule + its font link, remove unused Noto/Shippori/Gowun Batang overrides if nothing uses them (verify by computed style). Keep the user's handwriting look.
- P9: keep the stacking-row effect; remove the dark upward row shadow at <=700px; honor reduced motion.
- P11 location: DO NOW: Google Maps link built from coordinates for the facility tier (`query=lat,lon`, plus a directions link `dir/?api=1&destination=lat,lon`), text-search link for other tiers; area tier labelled "around <area>" with a radius that is not claimed as exact (use dashed circle, 3 km, hint text already says approximate); OSM + GSI attribution on every non-prefecture view; touch: map `dragging` disabled on touch devices unless two fingers (use `L.Map` option `dragging: !L.Browser.mobile` + a "use two fingers / expand" hint) so the drawer can scroll; aria-label states the precision tier; numbers validated (Number.isFinite, ranges) and links built with encodeURIComponent, rel=noopener. NEVER draw an exact-looking pin below the facility tier. LATER: list-wide map.
- P12 public status policy (tracker): publicly show only the check date and state `ok` / `changed` / `unreachable` (two failures) / `blocked` (as "자동 점검 불가"); closure/price/hours keyword flags are NOT shown publicly until a maintainer reviews them (remove that sentence from the drawer). Tracker work: save state + public file every ~50 URLs; stricter closure detection (notice area only; ignore bare 休止); `tools/tracker/reviewed.json` to dismiss items until the page hash changes; separate "cannot check automatically" state for robots/TLS errors with last-ok date; one-line maintainer summary + scheduling instructions (Windows Task Scheduler / cron) in the README.
- P15 cheap parts only: `<link rel="alternate" hreflang>` + canonical on the 3 shells, Promise.all for the independent fetches in db-loader/site.js, delete ja.css if nothing references it, unify the `?v=` suffix (single constant per release). Dictionary merge = LATER.
- P17: theme-color meta; no text under 13px anywhere (theme floors already 14px; fix style.css 10–11px leftovers).
